## 1. ROUTEROS VERSION COMPATIBILITY ARCHITECTURE

RouterOS underwent fundamental architectural revisions between v6 and v7 (specifically Linux kernel 3.3.5 -> 5.6.3, replacement of the routing engine with a completely new BGP/OSPF/FIB implementation, and revised CLI syntax).

VERA implements adaptive version handling across its parsers:

| Subsystem / Command | RouterOS v6 Syntax | RouterOS v7 Syntax | VERA Adaptive Handling |
| :--- | :--- | :--- | :--- |
| **Routing Table** | `/ip route print detail` | `/routing route print detail` | Auto-detects via `/system resource` |
| **OSPF Routing** | `/routing ospf route print`| `/routing route print where ospf`| Supported in `UnifiedRouteParser` |
| **BGP Routing** | `/routing bgp route print` | `/routing route print where bgp` | Supported in `UnifiedRouteParser` |
| **Paging Prevention**| `without-paging` | `without-paging` | Mandated on all CLI invocations |
| **Output Format** | Inline Key-Value (`kv`) | Indented Key-Value | Dual-format regex parser engine |

## 2. CLI PAGING HARDENING & TERMINAL CONTROL

When executing commands over an interactive SSH PTY, RouterOS will pause output with `-- [Q quit|D dump|down]` if terminal rows are exceeded. 

### 2.1 Hardening Rules Implemented:
1. **Explicit Flag:** Every command generated by VERA appends `without-paging` whenever the command supports it (e.g., `/interface print detail without-paging`).
2. **Terminal Dimensions:** [PersistentShell](file:///home/Lingga/Documents/project/Network_AI_Agent/VERA_ECOSYSTEM/agents/akane/connection_manager.py) requests a wide terminal buffer: `width=200`, `height=50`, `term='dumb'`.
3. **Paging Auto-Clear:** In [PersistentShell.execute()](file:///home/Lingga/Documents/project/Network_AI_Agent/VERA_ECOSYSTEM/agents/akane/connection_manager.py), if a prompt or paging indicator is encountered, a space bar character (` `) is sent non-blockingly to drain pending buffers.

## 3. COMMAND HARDENING & INJECTION SHIELDS

Located in [core/network_intelligence/command_execution.py](file:///home/Lingga/Documents/project/Network_AI_Agent/VERA_ECOSYSTEM/core/network_intelligence/command_execution.py) and verified by 63 unit tests in `test_routeros_command_hardening.py`:

### 3.1 Strict Read-Only Whitelist
The preflight and diagnostic runners permit only whitelisted command prefixes:
- `/system identity print`
- `/system resource print`
- `/system routerboard print`
- `/interface print`
- `/ip address print`
- `/ip route print`
- `/ip neighbor print`
- `/ip arp print`
- `/ip firewall filter print`
- `/ip firewall nat print`

### 3.2 Blocked Dangerous Directives
Commands containing any of the following patterns are rejected **prior to transport transmission**:
- `remove`, `add`, `set`, `disable`, `enable`, `reset`, `reboot`, `export`
- File operations: `/file print detail`, `/file remove`
- Script execution: `/system script run`
- Shell escape attempts: `;`, `|`, `&`, `$`, `` ` ``, `\n`
