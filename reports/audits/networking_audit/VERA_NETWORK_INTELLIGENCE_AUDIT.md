## 2. EPISTEMIC CLASSIFICATION MODEL

Every fact and conclusion generated by the intelligence engine is stamped with an epistemic category:

| Epistemic Class | Confidence Range | Definition & Criteria |
| :--- | :---: | :--- |
| `CONFIRMED_FACT` | 1.00 | Direct empirical evidence verified by hardware execution. |
| `STRONG_HYPOTHESIS` | 0.75 - 0.99 | Highly consistent with observed symptoms; alternative causes ruled out. |
| `PLAUSIBLE_HYPOTHESIS` | 0.50 - 0.74 | Consistent with partial evidence; further diagnostic probes recommended. |
| `SPECULATIVE` | < 0.50 | Corroborating data absent or stale; requires verification. |
| `RULED_OUT` | 0.00 | Directly contradicted by positive hardware observation. |
